# docs/ai/verification.md

## 책임

변경이 실제로 동작하는지 확인한다.

## 원칙

- 변경 범위에 맞는 최소 검증을 수행한다.
- 수행하지 못한 검증은 숨기지 않는다.
- 성능 수치는 측정 조건과 함께 기록한다.
- smoke test와 unit test를 구분한다.

## 기본 보고 형식

```txt
검증한 것:
수행한 명령:
결과:
수행하지 못한 것:
남은 위험:
```

## 성능 수치 기록 형식

```txt
측정 대상:
환경:
변경 전:
변경 후:
측정 방법:
한계:
```

## 금지

- 측정 없는 개선 수치 작성
- 실패한 테스트 생략
- 재현 조건 없는 성능 주장
- 테스트 삭제 후 성공 처리
